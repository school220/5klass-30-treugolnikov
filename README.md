# 20 Треугольников • Интерактивный тренажёр для электронной доски (5 класс)

Интерактивное веб-приложение для уроков математики в 5 классе по теме: **«Основание и высота треугольника»** (по учебнику, стр. 91–92 и рабочей тетради).

> ⚠️ **Без площади, периметра и углов** — все 20 задач посвящены исключительно пониманию элементов треугольника: основанию, высоте, перпендикулярности, противолежащей вершине, прямоугольным и тупоугольным треугольникам и типичным ловушкам.

## 🌟 Особенности приложения:
1. **Все 20 треугольников на одном экране (5×4):**
   - Учителю не нужно перелистывать слайды или прокручивать страницу у доски — весь класс видит все 20 задач одновременно в просторной и чёткой сетке 5 столбцов × 4 ряда.
   - Есть переключатель «В один экран (5×4)» и «Крупно (прокрутка 4×5)».
2. **Разделение по 4 ключевым темам урока:**
   - **Определи высоту (1–5):** остроугольный, прямоугольный (катет = высота), тупоугольный (внешняя высота), выбор между высотой и наклонной, основание вверху.
   - **Определи основание (6–10):** поиск основания для внутренней, внешней и боковой высоты, задания из рабочей тетради.
   - **Ловушки и правила (11–15):** чертежи с двумя перпендикулярами (задание 1c и 1d из РТ), линия не из вершины, угол не прямой (70° ≠ 90°), правило проведения пунктира по линейке.
   - **3 высоты и свойства (16–20):** разбор задания №2 со стр. 92 учебника со сменой трёх оснований (EG, EF, FG), теорема о 3 высотах, 2 высоты в прямоугольном треугольнике.
3. **🔒 Секретный режим учителя с паролем `5605741`:**
   - По умолчанию ответы скрыты от учеников.
   - При нажатии на замок или карточку появляется удобный сенсорный цифровой блок для ввода пин-кода пальцем прямо на интерактивной доске.
   - После ввода пароля `5605741` открывается пошаговое математическое решение с обоснованием и готовым ответом.
4. **Инструменты для доски:**
   - Встроенный цветной маркер для пометок поверх чертежей (5 цветов + ластик).
   - Таймер раунда на 1, 3, 5, 10 минут.
   - Режим фокусировки (нажатие на любой треугольник открывает его крупным планом для вызова ученика к доске).
