# 30 Треугольников • Интерактивный тренажёр для электронной доски (5 класс)

Интерактивное веб-приложение для уроков математики в 5 классе по теме: **«Основание, высота, углы и площадь треугольника»**.

## 🌟 Особенности приложения:
1. **Все 30 треугольников на одном экране (6×5):**
   - Учителю не нужно перелистывать слайды или прокручивать страницу у доски — весь класс видит все 30 задач одновременно.
   - Есть переключатель «В один экран (6×5)» и «Крупно (5×6)».
2. **На каждом треугольнике чётко написано задание:**
   - Разделение по темам: «Высота и основание (1–10)», «Площадь S (11–20)», «Углы и периметр (21–30)».
   - Векторная математическая точность без наложения текста на линии и фигуры.
3. **🔒 Секретный режим учителя с паролем `5605741`:**
   - По умолчанию ответы скрыты от учеников.
   - При нажатии на замок или кнопку «Показать ответ учителя» появляется удобный сенсорный цифровой блок.
   - После ввода пароля `5605741` открывается пошаговое математическое решение с формулами и готовым ответом.
4. **Инструменты для доски:**
   - Встроенный цветной маркер для пометок поверх чертежей (5 цветов + ластик).
   - Таймер раунда на 1, 3, 5, 10 минут.
   - Режим фокусировки (нажатие на любой треугольник открывает его крупным планом для вызова ученика к доске).
